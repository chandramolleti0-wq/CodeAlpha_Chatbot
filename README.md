# Basic Chatbot

This is a simple rule-based chatbot built using Python.

## Features
- Responds to basic user inputs
- Uses if-else conditions
- Runs in terminal

## Technologies Used
- Python

## How to Run
1. Run chatbot.py
2. Enter messages like "hello", "how are you"
3. Type "bye" to exit

## Concepts Used
- Loops
- Conditional Statements
- Functions
